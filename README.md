# Almanac

A [Chickadee Bandit](https://chickadeebandit.com/app-library/almanac) app.

Track recurring seasonal events — first frost, first blooms, first robin — and watch patterns emerge year over year.

## Features

- Recurring event types with one observation per year.
- Same-day, earlier-year reminders on the home screen.
- Years of household history, searchable.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-almanac/releases/latest/download/bundle.json
```
